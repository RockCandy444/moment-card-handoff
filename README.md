# 한 장 스튜디오

PNG·JPEG 이미지와 한글 문구를 조합해 1:1, 4:5, 9:16 PNG 카드를 만드는 공개 편집기입니다. 모든 편집은 브라우저 안에서 처리되며 업로드 서버나 계정이 필요하지 않습니다.

## 기능

- PNG·JPEG 불러오기, 지원하지 않는 파일과 과대 파일의 안전한 거부
- 문구 위치·크기·색·정렬과 이미지 확대·위치의 즉시 미리보기
- 미리보기와 같은 캔버스에서 PNG 저장
- 안정적인 UUID를 쓰는 템플릿 생성·불러오기·수정·삭제 및 브라우저 저장
- 전체 검증 뒤에만 적용하는 JSON 내보내기·가져오기
- 원본을 캔버스에 다시 그려 위치정보 등 원본 이미지 메타데이터 제거

## 공개 안전

앱에는 계정, 분석 도구, 외부 요청, API 키가 없습니다. 사용자가 고른 이미지는 서버로 전송하지 않습니다. 공개할 이미지의 사용 권한과 이미지 안의 개인정보는 사용자가 저장 전에 확인해야 합니다.
